any-i18n has three independent parts. The extension works on its own if you import translation
files by hand; the server and the CLI are optional helpers that produce those files.

## Requirements

- Chrome or Edge 116+, or Firefox 128+ (everything except the built-in image OCR), for the extension
- **Node.js 22.12+** for the CLI and the build script
- **Python 3.10+** for the translation server (`dict[str, str]` type syntax is used)

## Get the source

```bash
git clone https://github.com/rennerdo30/any-i18n.git
cd any-i18n
```

There are no dependencies to install for the extension itself — it is plain JavaScript loaded
directly by the manifest, with no bundler and no build step for development.

## Load the extension

<Tabs>
  <TabItem label="Chrome / Edge">
    <Steps>
      1. Open `chrome://extensions` (or `edge://extensions`).
      2. Enable **Developer mode**.
      3. Click **Load unpacked** and select the `extension/` directory.
    </Steps>
  </TabItem>
  <TabItem label="Firefox">
    <Steps>
      1. Run `npm run build:firefox`.
      2. Open `about:debugging#/runtime/this-firefox`.
      3. Click **Load Temporary Add-on**.
      4. Select `dist/firefox/manifest.json`.
    </Steps>

    Firefox needs the build: it runs the background code as an event page instead of a service
    worker, and the build also adds the `browser_specific_settings.gecko` block and drops the
    offscreen OCR, which Firefox does not support. Temporary add-ons are removed when Firefox
    restarts.
  </TabItem>
</Tabs>

The extension requests `storage`, `activeTab`, `scripting`, `contextMenus` and `offscreen`, plus
host access to `localhost`, `127.0.0.1` and `https://` hosts so it can reach your model; see
[Permissions](/any-i18n/guides/extension/#permissions).

## Choose a provider

Open the popup, press the gear button and pick a provider: LM Studio or Ollama on your machine, a
hosted API such as OpenAI, DeepSeek or OpenRouter, or the any-i18n server below. Press **Test
connection**, and you are ready to translate. Details: [Translation Providers](/any-i18n/guides/providers/).

## Start the translation server (optional)

The server translates batches of keys through an LLM backend and caches the results in SQLite.

<Tabs>
  <TabItem label="start.sh">
    ```bash
    ./server/start.sh
    ```

    The script creates `server/.venv` if it does not exist, installs
    `server/requirements.txt` into it, and runs `python -m server.run` from the repository root.
  </TabItem>
  <TabItem label="Manual">
    ```bash
    python3 -m venv server/.venv
    source server/.venv/bin/activate
    pip install -r server/requirements.txt
    python -m server.run
    ```

    Run it from the repository root — `server.main` imports its modules as `server.*`.
  </TabItem>
</Tabs>

`server/run.py` starts uvicorn on `0.0.0.0` at port `39418` with auto-reload enabled. Pass
`--no-reload` to disable reloading:

```bash
python -m server.run --no-reload
```

Check that it is up:

```bash
curl http://localhost:39418/api/health
# {"status":"ok","backend":"claude-cli"}
```

The default backend shells out to a locally installed CLI tool. See
[Configuration](/any-i18n/getting-started/configuration/) for the available backends and their
environment variables.

## Install the CLI (optional)

```bash
cd cli
npm install
```

The CLI is an ESM package with a single dependency (`commander`) and exposes the `any-i18n` binary:

```bash
npx any-i18n --help
```

## Build distributable packages

```bash
node scripts/build.js                    # chrome, firefox and edge
node scripts/build.js --browser chrome   # a single target
```

Each run wipes `dist/` and copies `extension/` into `dist/<browser>/`. For the Firefox target the
manifest is patched with `browser_specific_settings.gecko` (`id: any-i18n@extension`,
`strict_min_version: 109.0`). The resulting directories are ready to zip and upload.

The same commands are available through npm scripts:

```bash
npm run build
npm run build:chrome
npm run build:firefox
```
